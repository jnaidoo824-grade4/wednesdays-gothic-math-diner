# 🕷️ Wednesday's Gothic Math Diner

An interactive 3D web-based math adventure designed for Grade 4 students (ages 9–10). Step inside the Nevermore Academy Diner alongside **Wednesday Addams**, **Morticia**, **Gomez**, and **Thing** to master the entire Grade 4 curriculum through 3D WebGL gameplay, dynamic character voice synthesis, and viral WhatsApp challenges.

---

### ✨ Key Features

* **3D Addams Family World:** Built using Three.js with real-time dynamic lighting, atmospheric fog, interactive 3D math props, and animated character avatars.
* **Realistic Character Voice Engine:** Integrated Web Speech API speech synthesis customized with distinct pitch and speed profiles for Wednesday, Morticia, Gomez, and Thing.
* **100% Offline Audio & Visual FX:** Web Audio API sound synthesizers for pops, jingles, and buzzers paired with 3D particle gold confetti bursts with zero external media files.
* **3D Gothic Decor Shop:** Earn Gothic Coins by solving curriculum challenges and spend them to unlock 3D interior decorations (Cobweb Chandeliers, Stone Gargoyles, Velvet Booths, and Spooky Cauldrons) , with the actual 3D Decor shop after each level 
* **WhatsApp Engine:** Dynamic URL parameters shareable link 
* **PWA & Mobile Optimized:** Built directly for mobile touchscreens and desktop web browsers with offline Progressive Web App (PWA) installation capabilities.

---

### 📚 Full-Year Grade 4 Curriculum Scope

* **Term 1 (Cauldron Vault - Place Value & Rounding):** Place value up to 100,000, rounding to the nearest 10, 100, and 1,000, and multi-digit addition/subtraction.every level will be different addition and subtraction for term 1 maths
* **Term 2 (Thing's Monster Buffet - Multiplication & Division):** Multiplication tables up to 12×12, factors, multiples, 2-digit multiplication, and division with remainders.every level will be different multiplication and division for term 2 maths
* **Term 3 (Poison-Apple Pizza & Pie Shop - Fractions & Decimals):** Numerators and denominators, equivalent fractions (2/4 = 4/8), adding/subtracting like denominators, and introductory decimals (0.1 to 0.99).every level will be different  for term 3 maths
* **Term 4 (Diner Expansion - Geometry & Measurement):** Area calculation (Length × Width), Perimeter (2L + 2W), 2D/3D shapes, and line symmetry.every level will be different  for term 4 maths

---

### 🛠️ Tech Stack

* **Frontend Engine:** HTML5, CSS3, JavaScript (ES6+)
* **3D Graphics:** Three.js (WebGL rendering, point/spot lights, particle systems)
* **Voice & Audio:** Web Speech API & Web Audio API
* **Deployment:** GitHub Pages / Progressive Web App (PWA)
