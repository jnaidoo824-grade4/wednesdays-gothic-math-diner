Wednesday's Gothic Math Diner - Specifications
App Title: Wednesday's Gothic Math Diner
Target Audience: Grade 4 Students (Ages 9–10)
Mascot: Chef Mortis (Eccentric Gothic Master Chef)
Platform: Web Browser App & Offline Progressive Web App (PWA)
Full-Year Grade 4 Curriculum Map
Term 1 (Cauldron Vault): Place value up to 100,000, rounding to nearest 10, 100, and 1,000, multi-digit addition and subtraction.
Term 2 (Thing's Monster Buffet): Multiplication tables up to 12×12, factors, multiples, 2-digit multiplication, division with remainders.
Term 3 (Poison-Apple Pizza & Pie Shop): Numerators/denominators, equivalent fractions, adding/subtracting like denominators, introductory decimals (0.1 to 0.99).
Term 4 (Diner Expansion): Area (Length × Width), Perimeter (2L + 2W), 2D/3D shapes, line symmetry.
Core Gameplay & Viral Features
Base Decorating Shop: Spend earned Gothic Coins to unlock diner decor (cobweb chandeliers, velvet booths, stone gargoyles).
WhatsApp Challenge Engine: Send dynamic URL links (?challengeScore=X) directly via WhatsApp to invite friends to beat high scores.
Interactive FX: Pure Web Audio synthesized sounds (pops, jingles, buzzers), slice-pop animations, and purple/gold confetti particle bursts.
